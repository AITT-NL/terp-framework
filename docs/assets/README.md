# Terp Framework brand assets

The Terp family shares one green hill, amber building and blue wave, with the
same lowercase `terp` wordmark. Only the product subtitle and its accent differ.

| Product | Subtitle | On dark backgrounds | On light backgrounds |
| --- | --- | --- | --- |
| Studio | STUDIO | `#4f8ef7` | `#2563c9` |
| Framework | FRAMEWORK | `#35ce7d` | `#168447` |
| Standard | STANDARD | `#f6bc4c` | `#a36608` |

- `terp-logo.svg`: Terp Framework on a light background.
- `terp-logo-dark.svg`: Terp Framework on a dark background.
- `terp-mark.svg`: the shared symbol, including at favicon sizes.

The symbol always uses `#22c55e`, `#f59e0b` and `#4f8ef7`, respectively. Keep
its shapes and colours identical across products. The wordmark uses Segoe UI
with system sans-serif fallbacks, bold lowercase lettering and a smaller,
semibold uppercase subtitle. Keep long subtitles at their natural width.

These are standalone SVGs with no external assets or runtime dependencies.
Copies live in each product repository so documentation remains self-contained.
The README selects the light or dark wordmark for its background. Product names
remain readable in text; colour alone does not identify a product.
