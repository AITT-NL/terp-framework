# Security policy

## Reporting a vulnerability

Report it privately: on this repository's **Security** tab, choose **Report a vulnerability**.
That opens a private advisory that only the maintainers and you can see. Please do not open a
public issue or pull request for it.

Say what you found, where (file, version or commit) and how to reproduce it. A minimal proof of
concept helps.

## What happens next

- We acknowledge your report within **3 working days**.
- We send a first assessment, with the severity we assign, within **10 working days**.
- We agree a disclosure date with you. By default we publish an advisory when the fix is
  released, and no later than **90 days** after your report.

We credit you in the advisory unless you ask us not to.

## Supported versions

Security fixes go into the latest release. Upgrade to it to receive them.
